NXT + Open Roberta Lab

Registro del proceso para conectar un ladrillo LEGO NXT a Open Roberta Lab por USB en Windows 11: programa puente, driver Fantom y firmware.

Firmware del NXT

Open Roberta convierte los bloques del NXT a NXC, que corre sobre el firmware estándar de LEGO. Un NXT con leJOS no ejecuta esos programas. A diferencia del EV3, el NXT tiene un solo firmware a la vez: o leJOS o el de LEGO.

Decisión tomada: los ladrillos con leJOS quedan para Java; para Open Roberta se usan ladrillos con el firmware original de LEGO (Mindstorms). El cambio es reversible en ambos sentidos.

Programa puente de Open Roberta
01

Descargar el programa USB para NXT

Se descarga del repositorio oficial de Open Roberta en GitHub:

github.com/OpenRoberta/robertalab-usbprogram-nxt/releases

Archivo: OpenRobertaUSBNXTSetupEN-1.0.0.msi (versión de 2018).

⚠ AVISO DE EDGE

Edge muestra "no se descarga habitualmente" y no termina la descarga. Para conservar el archivo:

  1. Abrir el panel de descargas (Ctrl + J).
  2. En la fila del archivo, tocar los tres puntos ⋯ → Conservar.
  3. Si aparece otro aviso: Mostrar más → Conservar de todos modos.

"Notificar este archivo como seguro" no desbloquea la descarga: solo envía un reporte a Microsoft.

02

Instalar el programa

Doble clic en el .msi. Si aparece "Windows protegió su PC", tocar Más información → Ejecutar de todos modos. Completar el instalador con Next.

✓ HECHO
Driver Fantom de LEGO
03

Comprobar si Windows reconoce el NXT

Con el NXT encendido y conectado por USB, abrir el Administrador de dispositivos (clic derecho en Inicio).

  • Si aparece LEGO MINDSTORMS NXT: el driver ya está, pasar al paso 08.
  • Si aparece Dispositivo desconocido en Otros dispositivos: falta el driver.

Para confirmar que el dispositivo desconocido es el NXT: clic derecho → Propiedades → Detalles → Ruta de acceso a la instancia del dispositivo. El NXT se identifica con VID_0694&PID_0002.

Alternativa desde PowerShell, que busca cualquier dispositivo LEGO conectado:

Get-PnpDevice -PresentOnly | Where-Object InstanceId -like '*VID_0694*' | Select-Object FriendlyName, Class, Status
  • Sin resultados: Windows no ve el NXT (revisar cable, puerto y que el ladrillo esté encendido).
  • Status Error o Unknown: falta el driver Fantom.
  • Status OK: el driver está instalado.
04

Descargar el driver Fantom 1.20

LEGO ya no publica el driver del NXT. Se obtiene desde Softpedia:

drivers.softpedia.com — LEGO Mindstorms NXT Fantom Driver

En la página de descarga, hacer clic en Softpedia Secure Download (US). No usar botones grandes de "Download" en otras partes de la página: son publicidad.

Archivo correcto: NXT Fantom Drivers v120.zip, unos 9,7 MB. Si se descarga un .exe u otro nombre, no abrirlo.

05

Corregir el setup.ini

El instalador falla en Windows de 64 bits porque setup.ini apunta a un archivo que no existe.

  1. Descomprimir el zip.
  2. Abrir con el Bloc de notas: NXT Fantom Drivers\Windows\1.2\1.2.0\setup.ini
  3. Buscar la sección [LegoMindstormsNXTdriver64Supp.msi] y cambiar la línea Path= que está debajo.
  4. Guardar.
[LegoMindstormsNXTdriver64Supp.msi]
Path=Products\LEGO_NXT_Driver_64\NXT_D02\LegoMindstormsNXTdriver64.msi
06

Ejecutar setup.exe desde una terminal de administrador

Al abrir setup.exe con doble clic, Windows lo bloquea: "Esta aplicación se bloqueó como medida de seguridad", con Editor: Desconocido. La causa es que el instalador es de 2011 y su firma digital ya no es válida.

Solución: clic derecho en Inicio → Terminal (Administrador) y ejecutar:

# Ir a la carpeta del instalador
cd "$env:USERPROFILE\Downloads\NXT Fantom Drivers v120\NXT Fantom Drivers\Windows\1.2\1.2.0"
 
# Quitar la marca de "descargado de Internet"
Get-ChildItem -Recurse | Unblock-File
 
# Abrir el instalador
.\setup.exe
PLAN B

Si setup.exe sigue bloqueado

Instalar los dos paquetes directamente, en la misma terminal y carpeta. Se necesitan ambos: el programa de Open Roberta usa Java de 32 bits.

msiexec /i "Products\LEGO_NXT_Driver_32\NXT_D01\LegoMindstormsNXTdriver32.msi"
msiexec /i "Products\LEGO_NXT_Driver_64\NXT_D02\LegoMindstormsNXTdriver64.msi"
07

Elegir los componentes

  • LEGO MINDSTORMS NXT x64 Driver: dejarlo como está (se instala).
  • LEGO MINDSTORMS NXT x64 Driver Support: desplegar el menú y elegir Do not install this feature (queda con una ✕ roja).

Completar el instalador con las opciones por defecto.

08

Verificar el driver

Desconectar el NXT, esperar unos segundos y volver a conectarlo encendido. En el Administrador de dispositivos, el "Dispositivo desconocido" pasa a LEGO MINDSTORMS NXT.

Si sigue como desconocido: clic derecho → Actualizar controlador → Buscar automáticamente.

✓ FUNCIONÓ
Conexión con el Lab
09

Conectar con Open Roberta Lab

PENDIENTE DE PROBAR · NXT CON FIRMWARE LEGO
  1. Con el NXT encendido y conectado, abrir desde el menú Inicio el programa de Open Roberta para NXT.
  2. Tocar Connect. El programa muestra un código.
  3. En lab.open-roberta.org, elegir la tarjeta NXT.
  4. Ir a robot ▾ → connect… y pegar el código.
⚠ SI ALGO FALLA

Problemas posibles en el último paso

  • El programa no abre o se cierra enseguida: probablemente falta un JRE 8 de 32 bits (x86), disponible en Adoptium.
  • El programa abre pero no encuentra el NXT: revisar en el Administrador de dispositivos que siga como LEGO MINDSTORMS NXT y que el ladrillo no tenga leJOS.
  • El NXT tiene leJOS y se quiere pasar a LEGO: poner el ladrillo en modo actualización (apretar el botón de reset del agujerito trasero unos 4 segundos, hasta escuchar un "tic tic") y grabar el firmware LEGO MINDSTORMS NXT v1.31 (.rfw) con BricxCC → Tools → Download Firmware.
